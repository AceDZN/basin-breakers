# Basin Breakers · פורצי האגן: workbook catalog entry

- **Slug:** `basin-breakers`
- **Hebrew title:** פורצי האגן
- **English title:** Basin Breakers
- **Tagline (he):** חפרו תעלות והציבו סוללות כדי להסיט את השיטפון מהכפר אל הים. בכל אגן מקור אחר, שיפוע אחר, סלעים, אחו חדיר או גל נוסף, והמים זורמים רק לפי הגובה האמיתי של השטח.
- **Grades:** 8, 9
- **Orientation:** `any` (plays on a portrait phone: the map fits between the header and the tool dock; checked at 390×844)
- **Levels:** 24 authored maps; `?level=N` opens map N directly. Every map is open for practice in the standalone game, so there is no lock to skip. `index.html` and `campaign.html` are the same campaign; `freeform.html` is the older single-map sandbox and posts nothing.
- **Poster:** `workbook/poster.jpg` (1600×900, map 3 mid-flood: one trench carries the eastern surge past the three homes to the sea)
- **Stars:** the game has no star rating, so `level-complete` always sends `stars: 1` for a full rescue.

Module paths come only from `acedzn-tools/packages/catalog-geography/src` (`ids.ts`, `grade-8.ts`, `grade-9.ts`). They follow the source keys in [../CURRICULUM.md](../CURRICULUM.md): W8 `grade-8/chapter-6/water-resources`, E8 `grade-8/chapter-5/weathering-erosion`, R9 `grade-9/chapter-6/rivers-coasts`, M9 `grade-9/chapter-3/water-management`.
